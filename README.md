## CSTM Prep

This repository documents my preparation for the CSTM certification through structured, concept-first learning and practical reinforcement. The focus is on building strong technical foundations across core cybersecurity domains.

### 🎯 Approach

- Concept-first understanding  
- Practical reinforcement through labs (Immersive Labs, DVWA, HTB-style environments)   
- Methodology development and structured note-taking

## 📂 Repository Structure

### 🌐 Networking
Core networking principles including:
 - TCP/IP
 - Setting up static/dynamic IPs
 - Packet analysis
 - Foundational security concepts.

### 🌍 Web Security
Hands-on vulnerability study using lab environments:
- SQL Injection  
- Cross-Site Scripting (Reflected, Stored, DOM-based)  
- Authentication and session flaws  
- File upload vulnerabilities  

### 🪟 Windows
- Windows fundamentals  
- Services and permissions  
- Active Directory basics  
- Privilege escalation concepts  

### 🐧 Linux
- Linux fundamentals  
- File permissions and process management  
- Common services and ports  
- Privilege escalation techniques  

### 🧠 Technical Concepts
Focused breakdowns of individual topics, including: 
 - Technology
 - Networking
 - Protocols
 - Mitigation
 - Scope/Laws/Risk
